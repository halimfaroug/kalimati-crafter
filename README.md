# Arabic Vocabulary Builder

Convert the attached Claude artifact HTML file (Kalimati - My Words) into a full-featured, responsive React web application. Preserve all vocabulary categories, word lists, Arabic translations, pronunciation guides, emoji visual cues, flashcards/practice modes, audio speech synthesis, and progress/streak tracking with polished styling.
